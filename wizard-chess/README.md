# 3D Wizard Chess

A browser-based 3D wizard-themed chess game starter built with Three.js.

## Features

- 3D chessboard and pieces
- Wizard-themed visual direction
- Camera controls
- Click-to-select chess pieces
- Basic legal movement highlighting
- Local two-player game flow

## Planned enhancements

- Animated magical pieces
- Spell effects for captures
- Check/checkmate detection
- AI opponent
- Sound effects and ambient music
- Full mobile controls

## Run

Open `index.html` in a modern browser, or serve the directory with any static web server.
